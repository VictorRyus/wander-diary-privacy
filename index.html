01

총칙

완더 다이어리(이하 "앱")는 이용자의 개인정보를 소중히 여기며, 「개인정보 보호법」, 「정보통신망 이용촉진 및 정보보호 등에 관한 법률」 및 관계 법령을 준수합니다.

본 방침은 앱이 이용자로부터 어떤 개인정보를 수집하고, 수집된 정보를 어떻게 이용·보관·파기하는지 안내합니다. 본 방침은 앱 내 또는 관련 웹페이지를 통해 공개되며, 변경 시 앱 내 공지 또는 이메일을 통해 알려드립니다.

02

수집하는 개인정보 항목 및 수집 목적

수집 항목 수집 경로 수집 목적
이메일 주소, 소셜 로그인 식별자 (Google / Apple 계정) Firebase Authentication 사용자 계정 생성 및 식별, 로그인 인증
여행 일정, 여행지 텍스트, 날짜 정보 Firebase Firestore (이용자 직접 입력) 여행 기록 저장 및 기기 간 동기화
이용자가 직접 업로드한 여행 사진 Firebase Storage (이용자 직접 업로드) 여행 사진 저장 및 표시
입력한 장소명, 위도·경도 좌표 Google Maps API (이용자 직접 입력) 지도 시각화, 장소 검색 및 지오코딩
출발지·도착지 장소명 Google Directions API (이용자 직접 입력) 실제 도로망 기반 경로 렌더링
기기 사진 갤러리 접근 권한 기기 권한 요청 갤러리에서 여행 사진 선택 및 업로드
앱은 위치 정보를 자동으로 수집하지 않습니다. 장소 정보는 이용자가 직접 검색·입력하는 경우에만 처리됩니다.
03

개인정보의 보유 및 이용 기간

앱은 이용자가 서비스를 이용하는 동안 개인정보를 보유·이용합니다. 회원 탈퇴 또는 개인정보 삭제 요청 시 지체 없이 (7일 이내) 해당 정보를 파기합니다.

보유 항목 보유 기간 근거
계정 정보 (이메일, 식별자) 회원 탈퇴 시까지 서비스 제공 계약
여행 기록 (텍스트, 날짜, 장소) 이용자 삭제 요청 시까지 서비스 제공 계약
여행 사진 이용자 삭제 요청 시까지 서비스 제공 계약

단, 관련 법령에 의해 보존이 필요한 경우 해당 기간 동안 보관합니다. (예: 전자상거래법에 따른 계약·청약 기록 5년, 소비자 불만 기록 3년 등)

04

개인정보의 제3자 제공

앱은 이용자의 개인정보를 원칙적으로 제3자에게 제공하지 않습니다. 다만, 다음의 경우 예외적으로 제공될 수 있습니다.

① 이용자가 사전에 동의한 경우

② 법령의 규정에 따르거나, 수사 목적으로 법령에서 정해진 절차와 방법에 의해 수사기관이 요구하는 경우

05

개인정보 처리 위탁

앱은 서비스 운영을 위해 아래와 같이 개인정보 처리 업무를 외부에 위탁하고 있습니다. 위탁 계약 시 개인정보가 안전하게 관리될 수 있도록 관련 사항을 규정합니다.

수탁자 위탁 업무 보유 기간
Google LLC (Firebase) 데이터베이스 저장, 인증, 파일 스토리지 위탁 계약 종료 시까지
Google LLC (Maps Platform) 지도 시각화, 장소 검색, 경로 탐색 위탁 계약 종료 시까지

Google LLC의 개인정보 처리방침: https://policies.google.com/privacy

06

이용자의 권리 및 행사 방법

이용자는 언제든지 다음의 권리를 행사할 수 있습니다.

① 열람 요청: 자신의 개인정보 처리 현황 확인

② 정정·삭제 요청: 부정확하거나 불필요한 개인정보의 수정 또는 삭제

③ 처리 정지 요청: 개인정보 처리의 일시적 정지

④ 동의 철회: 수집·이용 동의를 언제든 철회

권리 행사는 앱 내 설정 메뉴(계정 삭제) 또는 아래 개인정보 보호책임자에게 이메일로 요청하시면 지체 없이 조치합니다. 이용자의 법정대리인 또는 위임받은 자도 동일하게 권리를 행사할 수 있습니다.

앱을 삭제하더라도 서버에 저장된 데이터는 자동 삭제되지 않습니다. 완전한 데이터 삭제를 원하시면 반드시 앱 내 계정 삭제 기능을 이용하거나 이메일로 요청해 주세요.
